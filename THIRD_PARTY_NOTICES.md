# Componentes y procedencia

Este inventario cubre los archivos seleccionados para el paquete local de revisión. No constituye una garantía de originalidad absoluta ni una revisión jurídica.

| Componente | Procedencia observada | Situación |
|---|---|---|
| HTML, CSS, JavaScript y pruebas | Generados y editados con asistencia de IA durante esta sesión | Código nuevo de este proyecto; licencia MIT aplicada por autorización del propietario. No se atribuye trabajo previo. |
| Cuatro CSV de ejemplo | Fixtures creados para las pruebas, con etiquetas y cantidades ficticias | No proceden de exportaciones empresariales. |
| Scripts Python | Código local que usa la biblioteca estándar | Sin paquetes descargados ni código de terceros vendorizado. |
| Navegador y Python | Herramientas instaladas en el equipo | No se redistribuyen con el ZIP. |
| Tipografía e iconografía | Fuentes del sistema y caracteres Unicode | Sin fuentes, imágenes, iconos o logos externos incorporados. |

No se identificaron dependencias npm/pip, CDN, bibliotecas de gráficos, SDK, recursos de red ni componentes de terceros copiados al producto. Se revisaron referencias de scripts/estilos y usos de APIs de red y almacenamiento. Las bibliotecas de prueba son locales y no necesitan servicios externos.

El código no incluye datos, capturas, documentos ni materiales de BI. Las etiquetas técnicas de medidas se usan para declarar el contrato del prototipo, sin acreditar afiliación empresarial.

El código original y los fixtures sintéticos incluidos se distribuyen bajo [MIT](LICENSE). La licencia permite reutilización conservando sus avisos y excluye garantías; no implica derechos sobre materiales empresariales o de terceros. No se identificaron componentes vendorizados sujetos a otras licencias. Esto es un inventario de procedencia observado, no una garantía absoluta de originalidad. Cualquier dependencia futura necesita origen, versión, licencia y avisos antes de incorporarse.
